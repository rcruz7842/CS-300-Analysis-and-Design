# Project Two - Course Advising Program

For Project Two, I built a course advising program in C++ using a binary search tree. The program reads course information from a CSV file and stores each course with its number, title, and prerequisites.

The program has a menu that allows users to load a course file, print a list of courses in alphanumeric order, or search for a specific course to see its information and prerequisites. I also added checks for duplicate courses, missing prerequisites, and invalid input.

I used a binary search tree because I could print the courses in order without having to sort them separately. This was the data structure I recommended in Project One after comparing it with vectors and hash tables.
